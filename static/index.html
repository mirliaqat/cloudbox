Strategy: load-aware

Stop a node to simulate a crash. Chunks direct to least loaded nodes.

How to test it

  1. Upload a file (a photo or PDF).
  2. Stop node-1. The file now shows 1 copy, but Download still works.
  3. Press Repair. Copies go back to 2 on the running nodes.
  4. Stop a second node. Repaired files still download.
  5. Create a Share link, open it, then change one letter: 403.
  6. Click Compare Load Balancing to view skew benchmarks.
